
# Week 2 Day 2 – JSON Prompting for Tamil Visuals

## Project Objective
To create culturally authentic Tamil-themed images and a short video using reusable JSON prompting.

## Theme
Chettinad Traditional Courtyard during Margazhi.

## Tools Used
- ChatGPT / AI Image Generator
- AI Video Generator
- JSON
- VS Code
- Git and GitHub

## Deliverables
1. Reusable tamil_prompt.json template.
2. Image 1 – Base template.
3. Image 2 – Golden hour variation.
4. Image 3 – Close-up camera variation.
5. One 5-second AI-generated video.

## JSON Experiments
- Image 1: Original template.
- Image 2: Changed setting.time_of_day.
- Image 3: Changed camera.shot.
- Video: Added motion fields.

## Learning Outcome
Learned how structured JSON prompts help control image generation by changing individual parameters while keeping other visual elements consistent.
